# Sales-Data-Statistical-Analysis-Using-Python
This project demonstrates statistical data analysis using Python. It covers important statistical concepts such as Percentiles, Quartiles, Histogram, Skewness, Covariance, Correlation, and Dependency Analysis using a sample sales dataset.
This project demonstrates statistical data analysis using Python. It covers important statistical concepts such as:

Percentiles
Quartiles
Histogram
Skewness
Covariance
Correlation
Dependency Analysis

The project uses a sample sales dataset to analyze the relationship between Advertisement and Sales using Python libraries.
